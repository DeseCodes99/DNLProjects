# DNL Projects React Website

Recreated as a standard React + Vite project from the saved DNL Projects site content.

## Run it

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run: `npm install`
5. Run: `npm run dev`
6. Open the localhost URL Vite shows you.

## Main files

- `src/App.jsx` — website structure/content
- `src/styles.css` — all styling
- `src/main.jsx` — React entry point

The saved ChatGPT Site did not expose its original source code or image assets for export, so this is a clean React/Vite reconstruction rather than the original generated source. Replace the placeholder gradient project imagery with your own photos in `src/App.jsx` / `src/styles.css`.
